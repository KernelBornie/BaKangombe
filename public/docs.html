BaKangombe Email Validation & Enrichment API

Overview

BaKangombe offers a real‑time API to validate emails, detect disposable addresses, verify MX records, and enrich email addresses with company and person data (using Hunter.io). Free tier available – no API key required.

Base URL

https://ba-kangombe.vercel.app

Authentication

Free tier (validation only): No authentication required.

Premium tier (enrichment & batch): Requires an API key obtained after subscribing. Include the key in the X-API-Key header.

curl -H "X-API-Key: YOUR_API_KEY" https://ba-kangombe.vercel.app/api/enrich -d '{"email":"user@example.com"}'

Endpoints

POST /api/validate

Validates a single email address. Returns syntax check, MX records, disposable status, and a quality score (0‑100). Free tier.

Request body:

{ "email": "user@example.com" }

Example response:

{
  "email": "user@example.com",
  "valid": true,
  "has_mx": true,
  "has_a": false,
  "is_disposable": false,
  "is_free_provider": false,
  "score": 100
}

POST /api/enrich

Enriches an email with verification data from Hunter.io. Requires premium API key in X-API-Key header.

Request body: same as validation.

Example response:

{
  "email": "bill.gates@microsoft.com",
  "verified": true,
  "accept_all": false,
  "disposable": false,
  "webmail": false,
  "mx_records": true,
  "score": 95,
  "name": "Bill Gates",
  "company": "Microsoft"
}

POST /api/validate/batch

Upload a CSV file (first column contains emails) and get validation results for all emails. Requires premium API key.

Request: multipart/form-data with field file (CSV file).

Example response:

{
  "count": 2,
  "results": [
    { "email": "a@b.com", "valid": true, "score": 100 },
    { "email": "invalid", "valid": false, "reason": "invalid syntax" }
  ]
}

Code Examples

cURL – Validation (free)

curl -X POST https://ba-kangombe.vercel.app/api/validate -H "Content-Type: application/json" -d '{"email":"user@example.com"}'

JavaScript (fetch) – Enrichment (premium)

fetch('https://ba-kangombe.vercel.app/api/enrich', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'X-API-Key': 'YOUR_API_KEY'
  },
  body: JSON.stringify({ email: 'bill.gates@microsoft.com' })
})
.then(res => res.json())
.then(console.log);

Python – Batch validation (premium)

import requests

files = {'file': open('emails.csv', 'rb')}
headers = {'X-API-Key': 'YOUR_API_KEY'}
response = requests.post('https://ba-kangombe.vercel.app/api/validate/batch', headers=headers, files=files)
print(response.json())
