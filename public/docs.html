⚡ 100% Offline Architecture PWA Standard

BaKangombe is engineered to operate seamlessly with zero internet connectivity. The offline system is composed of three interconnected layers:

  • Service Worker Cache-First Engine (/sw.js): Precaches application HTML pages, CSS stylesheets, client scripts, icon assets, and Google Fonts. Intercepts navigation and serves cached shells immediately.
  • Universal Fetch Interceptor (/pwa-bridge.js): Transparently captures API requests when offline, executing client-side validation, heuristic AI responses, and local ledger entries.
  • IndexedDB Local Storage (BaKangombeOfflineDB): Persists CV drafts, offline mobile money transactions, and pending mutations in an automatic background synchronization queue.
