BaKangombe API Documentation

Base URL: https://ba-kangombe.vercel.app

Authentication

Free tier: no API key required.
Premium tier: include X-API-Key: YOUR_KEY header.

Endpoints

POST /api/validate

Free – validate email syntax, MX, disposable status.

curl -X POST https://ba-kangombe.vercel.app/api/validate -H "Content-Type: application/json" -d '{"email":"user@example.com"}'

POST /api/enrich

Premium – enrichment via Hunter.io.

curl -X POST https://ba-kangombe.vercel.app/api/enrich -H "Content-Type: application/json" -H "X-API-Key: YOUR_KEY" -d '{"email":"bill.gates@microsoft.com"}'

POST /api/validate/batch

Premium – batch CSV validation.

curl -X POST https://ba-kangombe.vercel.app/api/validate/batch -H "X-API-Key: YOUR_KEY" -F "file=@emails.csv"

POST /api/domain/score

Premium – domain security score (SPF/DKIM/DMARC).

curl -X POST https://ba-kangombe.vercel.app/api/domain/score -H "Content-Type: application/json" -H "X-API-Key: YOUR_KEY" -d '{"domain":"github.com"}'

POST /api/disposable

Premium – check if email is from a disposable domain.

curl -X POST https://ba-kangombe.vercel.app/api/disposable -H "Content-Type: application/json" -H "X-API-Key: YOUR_KEY" -d '{"email":"temp@mailinator.com"}'

POST /api/website/generate

Premium – generate landing page HTML.

curl -X POST https://ba-kangombe.vercel.app/api/website/generate -H "Content-Type: application/json" -H "X-API-Key: YOUR_KEY" -d '{"template":"landing","title":"My Site","content":"Hello"}'

POST /api/feedback

Free – submit feedback (sends confirmation email).

curl -X POST https://ba-kangombe.vercel.app/api/feedback -H "Content-Type: application/json" -d '{"name":"User","email":"user@example.com","message":"Great API!"}'
